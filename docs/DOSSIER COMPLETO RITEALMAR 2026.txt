14. SEGURIDAD WEB Y PROTECCIÓN DEL WEBHOOK

Se corrigió un punto importante de seguridad.

Antes existía riesgo de exponer directamente el webhook de Apps Script en el frontend.

Ese riesgo se corrigió.

Arquitectura segura actual:

Frontend RITEALMAR
→ /api/save-to-sheets
→ Cloudflare Worker
→ Secret GOOGLE_SHEETS_URL
→ Apps Script
→ Google Sheets CRM

Medidas aplicadas:

- Webhook directo eliminado del frontend.
- Endpoint interno /api/save-to-sheets.
- Cloudflare Worker como capa intermedia.
- Secret GOOGLE_SHEETS_URL protegido en Cloudflare.
- Webhook de Apps Script rotado.
- Dist escaneado.
- No hay claves sensibles visibles.

Elementos protegidos:

- GOOGLE_SHEETS_URL.
- Apps Script webhook real.
- GEMINI_API_KEY.
- RESEND_API_KEY.
- Variables de entorno.
- Lógica de CRM.

Escaneos realizados:

script.google.com: no encontrado
VITE_GOOGLE_SHEETS_WEBHOOK_URL: no encontrado
GEMINI_API_KEY: no encontrado
RESEND_API_KEY: no encontrado
GOOGLE_SHEETS_URL: no encontrado
