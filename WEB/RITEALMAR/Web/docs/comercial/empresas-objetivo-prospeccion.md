# Guía de Prospección: Selección de Empresas Objetivo

El objetivo de esta guía es evitar la prospección aleatoria y centrar los esfuerzos comerciales en empresas con una alta probabilidad de necesitar la auditoría IA y los servicios de automatización de RITEALMAR.

---

## 1. Perfil ideal de empresa (ICP)
- Pyme o empresa pequeña/mediana.
- Tiene web o presencia digital mínima (redes sociales, ficha de Google).
- Recibe consultas frecuentes por email, WhatsApp o formulario web.
- Depende de una atención rápida al cliente para no perder ventas.
- Usa procesos de gestión eminentemente manuales y dependientes de personas.
- Realiza tareas repetitivas a diario.
- Tiene margen comercial para invertir si percibe una mejora en su rentabilidad, captación o seguimiento.

## 2. Sectores prioritarios
El enfoque inicial B2B se centrará en los siguientes verticales, por su alto volumen de consultas repetitivas:
- Clínicas (Médicas, Dentales, Estéticas, Fisioterapia).
- Inmobiliarias.
- Asesorías y Gestorías.
- Empresas de servicios B2B/B2C.
- Academias o centros de formación.
- E-commerce.
- Empresas de reformas, instalaciones o mantenimiento.
- Despachos profesionales (Abogados, Arquitectos).

## 3. Señales de oportunidad (Banderas Verdes)
Cuando se revisa la web o el perfil de un prospecto, buscar estos indicios:
- Tienen un botón de WhatsApp visible en la web para consultas.
- Usan formularios de contacto muy básicos sin cualificación.
- Es evidente que responden manualmente a un volumen alto de consultas repetitivas.
- No disponen de ningún tipo de chatbot o asistente inicial automático.
- Cuentan con varias sedes físicas o múltiples servicios/productos.
- Tienen un buen volumen de publicaciones en redes, pero el embudo de captación está roto o es muy manual.
- Tienen procesos administrativos densos y dependientes de hojas de cálculo o papeles.
- La web parece desactualizada o actúa solo como "folleto" digital poco orientado a la conversión directa.

## 4. Señales de bajo encaje (Banderas Rojas)
No priorizar empresas que cumplan con estas características:
- Empresa sin presencia digital mínima o nula.
- Negocio unipersonal de muy bajo volumen de trabajo que no recibe consultas.
- Ausencia de un equipo estructurado o procesos comerciales estables.
- Perfil que desde el inicio busca "algo gratis" o soluciones do-it-yourself.
- Empresa que al ser contactada no muestra interés real, evade respuestas o ignora seguimientos.
- No se detecta un problema concreto que la IA o la automatización pueda resolver.

## 5. Sistema simple de prioridad (Scoring)
Evaluar rápidamente a la empresa (Puntuación de 1 a 5 por variable, siendo 5 el valor máximo):

| Criterio | Puntuación (1-5) |
|----------|------------------|
| Volumen probable de consultas | |
| Nivel de trabajo manual evidente | |
| Potencial de automatización real | |
| Capacidad de decisión (Contacto directo) | |
| Urgencia del problema (Competencia, caos) | |
| Encaje con servicios RITEALMAR | |
| **TOTAL** | |

**Clasificación de Prioridad:**
- **20 - 25 puntos:** Prioridad Alta (Contacto directo inmediato)
- **13 - 19 puntos:** Prioridad Media (Entrada en flujo de prospección estándar)
- **0 - 12 puntos:** Prioridad Baja (Descartar o dejar para largo plazo)

## 7. Regla Final
> **No contactar empresas al azar.** Priorizar siempre a aquellas que denoten señales claras de depender de procesos repetitivos, de tener una atención muy manual o de disponer de un sistema de captación claramente mejorable.
