# Checklist Diario Comercial - RITEALMAR

Esta guía operativa debe usarse cada día para sistematizar la captación, organizar el seguimiento y asegurar que ningún lead se queda sin atención profesional.

---

## 1. Revisión de leads entrantes
- [ ] Revisar envíos del formulario de "Auditoría IA Gratuita".
- [ ] Revisar el Google Sheets de leads existente.
- [ ] Revisar la bandeja de entrada del correo.
- [ ] Revisar notificaciones y mensajes de WhatsApp.
- [ ] Marcar y actualizar el estado de cada lead recibido.

## 2. Respuesta a nuevos leads
- [ ] Usar la plantilla de "respuesta rápida" correspondiente (Email o WhatsApp).
- [ ] Completar la "mini auditoría manual" para cualificar la necesidad del prospecto.
- [ ] Clasificar la prioridad del lead (Alta, Media, Baja).
- [ ] Definir claramente la siguiente acción (ej. llamada, demostración, seguimiento).

## 3. Prospección diaria
- [ ] Seleccionar entre 5 y 10 empresas objetivo nuevas para contactar hoy.
- [ ] Elegir el mensaje de prospección adecuado (según sector o canal).
- [ ] Enviar el mensaje por el canal correspondiente (LinkedIn, Email, WhatsApp).
- [ ] Registrar este primer contacto en la hoja de control existente.
- [ ] Anotar la fecha exacta para hacer el primer seguimiento (Día +3 o +4).

## 4. Seguimiento (Follow-up)
- [ ] Revisar la lista de leads contactados previamente que no han dado respuesta.
- [ ] Enviar el mensaje amable de seguimiento correspondiente al Día 2, Día 5 o Día 10.
- [ ] Actualizar el estado en el embudo (CRM o Sheets).
- [ ] *Nota: No insistir de forma agresiva. Si tras varios intentos no hay respuesta, pasar a estado "Frío".*

## 5. Revisión de oportunidades
- [ ] Detectar si hay sectores concretos que se repiten en las consultas recientes.
- [ ] Detectar cuáles son los servicios de IA o automatización más solicitados.
- [ ] Detectar las objeciones más frecuentes para mejorar el argumentario.
- [ ] Anotar las posibles ideas o mejoras futuras que sugieren los leads.

## 6. Cierre del día
- **Número de contactos prospectados (enviados):** ______
- **Número de respuestas recibidas:** ______
- **Leads totalmente nuevos de hoy:** ______
- **Próxima acción principal (para mañana):** ______
- **Qué NO tocar:** (Recordatorio de que la web sigue en recolección de datos).

---

## Regla principal
> **No cambiar la web por intuición.** Primero registrar datos reales y decidir mejoras con base en leads, conversiones y Search Console.
