# Uso de Google Sheets para Gestión de Leads

Este documento establece las buenas prácticas para la gestión del flujo comercial utilizando la hoja de Google Sheets existente de RITEALMAR.

## Proceso Diario
1. **Revisar nuevos leads cada día:** Asegurarse de procesar rápidamente las nuevas entradas provenientes del formulario de auditoría.
2. **Marcar estado del lead:** Actualizar la columna de estado inmediatamente tras cualquier acción comercial para reflejar la realidad de la oportunidad.
3. **Añadir notas después de cada contacto:** Dejar siempre constancia en la hoja sobre el resumen de las llamadas o correos (dolores, presupuesto, bloqueos).
4. **Fijar próxima acción:** Todo lead activo debe tener un "siguiente paso" claro (llamada, correo, propuesta).
5. **Actualizar fecha de seguimiento:** Anotar la fecha en la que se debe ejecutar la próxima acción para no perder el rastro del cliente.
6. **No duplicar registros:** Si un cliente vuelve a rellenar el formulario, combinar la información en el registro original existente.
7. **Mantener limpio el estado comercial:** Filtrar o mover a otra pestaña los leads "Perdidos" o "Sin respuesta" periódicamente para mantener el foco en los activos.

## Estados Recomendados
Asegúrate de alinear la hoja con los siguientes estados lógicos del pipeline comercial:
- **Nuevo**
- **Contactado**
- **En análisis**
- **Propuesta enviada**
- **Ganado**
- **Perdido**
- **Sin respuesta**

> **Importante:** Esta hoja ya está integrada con el flujo del formulario. No alterar nombres de columnas base ni crear copias que rompan la sincronización de los datos.
